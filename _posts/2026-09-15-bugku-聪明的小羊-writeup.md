## 一、题目信息

- **题目名称**：聪明的小羊
- **题目类型**：Misc (杂项) - 图片隐写
- **靶场来源**：Bugku CTF
- **考察知识点**：PNG 图片结构分析、LSB（最低有效位）隐写、Stegsolve 工具的使用

## 二、解题过程

### 1. 初步分析
下载并解压附件，得到一张名为 `聪明的小羊.png` 的图片。直接双击打开，图片看起来只是一张正常的卡通画，没有肉眼可见的提示文字或可疑区域。

### 2. 常规排查（基础隐写排除）
- **记事本/Hex查看文件末尾**：右键使用记事本打开，拉到最后，只有乱码，没有发现 `flag{...}` 明文。
- **搜索压缩包头**：使用 010 Editor 或在线 Hex 工具搜索 `50 4B`（ZIP 文件头），未找到附加的压缩包数据。
- **查看文件属性**：右键图片 -> 属性 -> 详细信息，备注等字段没有隐藏信息。

排除以上基础套路后，可以初步判断出题人利用了图片像素本身来隐藏数据，大概率是**LSB 隐写**。

### 3. 使用 Stegsolve 进行 LSB 数据提取
LSB 隐写是将信息藏在图片像素 RGB 颜色的最低有效位中，肉眼无法察觉，需借助专业工具。

**操作步骤：**
1. 打开 **Stegsolve**（需提前安装 Java 环境）。如果还没有，可以通过百度搜索下载。
2. 点击左上角的 `File -> Open` 载入图片 `聪明的小羊.png`。
3. 点击上方菜单栏的 `Analyse -> Data Extract`（数据提取）。
4. 在弹出的窗口中，勾选右侧的 **`LSB`** 相关选项：
   - 尝试勾选 `Red 0`, `Green 0`, `Blue 0`（即提取 RGB 通道的最低有效位）。
   - 如果直接提取出来是一堆乱码，尝试将 `Bit Order` 设置为 `MSB First` 或者 `LSB First`。
5. 点击右下角的 **`Preview`**，观察左侧的文本预览框。通过切换不同的通道组合（如只勾选 Red 0，或同时勾选 R/G/B 0），直到预览框出现明显的 `flag{...}` 格式字符串。
6. 点击 **`Save Bin`** 将提取出的数据保存为文件，或者直接复制出现的文本。

### 4. 获取 Flag
通过调整 LSB 通道，成功提取出隐藏的明文信息。
